LAPORAN ANALISIS DASHBOARD PENJUALAN MOBIL 
2001-2020

Dashboard ini menyajikan hasil analisis terhadap data penjualan mobil dalam kurun waktu tahun 2001–2020. Fokus analisis mencakup tren pertumbuhan tahunan (YoY), performa merek dan model mobil, serta pangsa pasar berdasarkan merek utama. Tujuan dari laporan ini adalah untuk memberikan gambaran menyeluruh mengenai dinamika pasar otomotif, mengidentifikasi merek dan model unggulan, serta menganalisis perubahan tren penjualan yang dapat dijadikan dasar strategi bisnis dan pemasaran ke depan.
